# TRICE Benchmark Suite

The benchmark suite measures computational properties rather than claiming human equivalence.

## Required benchmark families

- **Homeostasis:** recovery from controlled perturbations.
- **Coupling:** stability and information flow across neural/immune/endocrine subsystems.
- **Energy:** useful work per resource budget under matched tasks.
- **Memory:** retention, retrieval, contextual interference, and controlled decay.
- **Adaptation:** performance after distribution shift without catastrophic degradation.
- **Fault tolerance:** recovery after simulated module failures.
- **Evolution:** improvement, diversity retention, convergence, and reproducibility.
- **Whole-body coverage:** registry completeness and dependency integrity.

Every benchmark must record seed, code version, configuration hash, model fidelity, metrics, runtime, and uncertainty/error notes.

No benchmark score is a claim of consciousness or biological identity.
